作業 05

Before this assignment, the only image-generation interface I was familiar with was StableDiffusion-WebUI, so trying ComfyUI was a fresh experience for me. I found ComfyUI more flexible and visual because it lets users clearly see the workflow and adjust each part of the generation process. At the same time, this assignment made me realize that my prompt-writing skills still need improvement, since some details like the eyes, hair, and facial expression were not generated as naturally as I hoped. In particular, I wanted Himmel’s expression to look more striking and charismatic, but the result did not fully match my expectation. Even so, this exercise helped me better understand how model choice, prompts, and parameters all affect the final image.
